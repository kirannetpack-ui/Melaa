# Melaa implementation status — 4 October 2026

This is a protected product preview, not a public or money-moving marketplace. A feature is marked **implemented** only when present in the repository and covered by a local or hosted check; it does not imply a third-party compliance certification.

| Area | Implemented now | Still required before public launch |
| --- | --- | --- |
| Buyer/seller chat | Product-linked threads, mobile chat UI, unread counts, 12-second refresh while the message view is open, message/conversation reports, admin access to all threads, flagged-message counts, hide/restore, close/reopen, and an open-report queue with resolution audit. | Real-time delivery/push notifications, evidence-retention policy, moderator roles and appeal workflow, multilingual/attachment/OCR review, and privacy notices for admin-visible chat. |
| Account and application security | Salted scrypt passwords, hashed server-side sessions, role checks, strict production cookies, origin checks, restrictive headers, prepared SQL, shared auth/chat throttling, private media, seller/content approval gates, audit records, and 0 high-severity production dependency findings in the latest `npm audit` run. | Verified email and recovery, admin MFA, independent penetration test, bot/WAF controls, monitoring and alerting, backup/restore drills, retention/deletion policy, safe media decoding/re-encoding and malware scan. No codebase can honestly be described as perfectly secure. |
| Fake people/products and sexual content | Pending seller approval, product/post moderation before publication, text-rule blocking, basic file-signature checks, private unpublished media, user reporting, suspension, admin review and audit. | Accredited identity/business verification, ownership/provenance evidence and brand authorization, duplicate-account/device detection, specialist nudity/CSAM hash-match and malware providers, OCR/video review, trained high-severity escalation and jurisdiction-specific prohibited-goods rules. Current rules do **not** reliably detect all unwanted content. |
| Margin and anti-circumvention | Admin-configurable retail/wholesale commission and payout-hold settings, per-line projected commission on recorded orders, seller fee disclosure, on-platform messaging and contact/payment solicitation blocking. | Contracted Nepal-eligible licensed marketplace payment/settlement partner; fee capture, signed webhooks, ledger, refunds/chargebacks, payout reconciliation, fulfillment, buyer protection and lawful terms. No money is collected now. Off-platform dealing cannot be made impossible; trustworthy service and clear terms reduce its incentive. |
| Seller terms and pricing | Internal planning defaults of 5% retail/3% wholesale, protected migration of untouched old defaults, concise versioned seller terms with registration consent and timestamp, separate-written-agreement wording, admin fee-change audit. | Nepalese legal review, actual payment-provider cost model, individual written seller fee schedules, a contracted 2% high-volume wholesale tier, enforceable settlement/refund rules and seller notice channel. |
| Discovery and post actions | Search- and follow-influenced paginated feed, automatic loading while scrolling, honest caught-up state, recommendation signals, private structured suggestions to seller with admin visibility, existing product/occasion tags on image and uploaded video. | Scalable recommendation indexes, opt-in preference history, bias/privacy evaluation, verified-purchase reviews and relationship disclosures for testimonial content. |
| Occasion planning | In-app reminders calculated from saved personal dates and admin-reviewed annual dates, plus a labelled demo card. | Opted-in delivery by email/push, reliable scheduler, delivery receipts, localized timezone rules and sourced annual dates. |
| Live video | Uploaded MP4 stories with product/occasion tags. | True moderated livestreaming needs an external streaming service, ingest/recording, latency controls, moderation and provider credentials; Vercel Functions cannot serve as a WebSocket media server. |

Vercel deploys `main` automatically into the `melaa` project with Turso and private Blob. Vercel Authentication is set to **All Deployments**; keep it that way until the launch gates above are complete. See [DEPLOYMENT.md](DEPLOYMENT.md), [SECURITY.md](SECURITY.md), [CONTENT_SAFETY.md](CONTENT_SAFETY.md), and [MARKETPLACE_OPERATIONS.md](MARKETPLACE_OPERATIONS.md) for procedures and sources.
